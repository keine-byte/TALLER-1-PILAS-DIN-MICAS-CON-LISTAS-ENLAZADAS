
### TOKENS: (A+B)*C

------------------------------------------------------------------
CONVERSIÓN INFIJA -> POSTFIJA (Shunting Yard de Dijkstra)
Tokens de entrada: ( A + B ) * C
Nota: en las pilas se muestra primero la cima (izquierda).
  1. token '('      -> push('(')                          | Pila operadores: [(]
  2. operando 'A' -> salida directa                 | Salida: A
  3. operador '+' -> push('+')                        | Pila operadores: [+, (]
  4. operando 'B' -> salida directa                 | Salida: A B
  5. token ')'      -> desapilar hasta encontrar '('      | Pila operadores: [+, (]
      operador '+' sale a la salida            | Salida: A B +
      se descarta '('                                | Pila operadores: []
  6. operador '*' -> push('*')                        | Pila operadores: [*]
  7. operando 'C' -> salida directa                 | Salida: A B + C
      fin de tokens: '*' sale a la salida         | Salida: A B + C *
RESULTADO POSTFIJO: AB+C*   (con espacios: A B + C *)
==================================================================

### EVALUACIÓN POSTFIJA DE 23+4* (caso del taller)

------------------------------------------------------------------
EVALUACIÓN POSTFIJA de: 2 3 + 4 *
Se recorre la expresión de izquierda a derecha.
Nota: en las pilas se muestra primero la cima (izquierda).
  1. operando '2' -> push(2) | Pila: [2.0]
  2. operando '3' -> push(3) | Pila: [3.0, 2.0]
  3. operador '+' -> pop()=3, pop()=2 | operación: 2 + 3 = 5 | push() | Pila: [5.0]
  4. operando '4' -> push(4) | Pila: [4.0, 5.0]
  5. operador '*' -> pop()=4, pop()=5 | operación: 5 * 4 = 20 | push() | Pila: [20.0]
Pila final: []  ->  Resultado final = 20  (operaciones: 2 + 3 = 5 ; 5 * 4 = 20)
